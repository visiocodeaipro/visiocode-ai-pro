# Contributing to Visiocode AI Pro

We love your input! We want to make contributing to this project as easy and transparent as possible.

## How to contribute
1. **Fork the repo** and create your branch from `main`.
2. **Make your changes** and add tests if relevant.
3. **Open a Pull Request** describing your changes clearly.
4. **Follow our code style** (Pylint compliant).

## Reporting bugs
If you find a bug, please create an **Issue** and provide:
- Steps to reproduce.
- Expected behavior.
- Screenshots if possible.
