## 🎯 Overview

**Visiocode AI Pro** is a high-performance, private desktop ecosystem engineered for developers and technical founders who follow the *Build in Public* methodology. It runs completely offline to scan your local repository status, track background business logic, and autonomously generate production-ready viral technical branding content, video assets scripts, and visual hierarchies.

---

## 🚀 Key Features

* **🛡️ 100% Local Privacy:** No API keys, no external cloud latency. Powered entirely by offline LLM ecosystems and efficient multimodal vision pipelines.
* **⚡ Code-to-Content Automation:** Processes structural code updates, active commits, and framework setups into engaging developer-focused marketing assets.
* **🎨 Precision UI/UX Framework:** Built with a modern, responsive **CustomTkinter** interface optimized for rapid configuration and visual hierarchy tracking.
* **👁️ Vision-Driven Content Analysis:** Integrates high-efficiency vision processing models (Moondream) to inspect asset layers, slogans, and thumbnails layouts before exporting.

---

## 🛠️ Architecture & Tech Stack

| Layer | Component / Tool | Purpose |
| :--- | :--- | :--- |
| **Frontend GUI** | `CustomTkinter` | Clean, dark-themed responsive desktop control panel |
| **Inference Engine** | `Ollama` | Secure local LLM runtime execution environment |
| **Vision Pipeline** | `Moondream` | Multimodal analysis of generated UI frames and visual structures |
| **Core Scripts** | `screen_agent.py` / `generate_icon.py` | Window capture automation and runtime visual asset rendering |

## 🚦 Quick Start (Local Setup)

### Prerequisites
1. Install Python 3.11+
2. Download and run Ollama locally.
3. Pull the required models: ollama pull moondream

### Execution Steps
# Clone the repository
git clone https://github.com/visiocodeaipro/visiocode-ai-pro.git
cd visiocode-ai-pro

# Run the core dashboard agent
python screen_agent.py
